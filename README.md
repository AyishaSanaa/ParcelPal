\# ParcelPal



ParcelPal is a simple package management dashboard that helps users keep track of their online orders in one place.



\## Problem



People order products from different shopping platforms and often find it difficult to remember their orders and delivery status.



\## Solution



ParcelPal provides one dashboard where users can add packages, view order details and update delivery status.



\## Features



\- Dashboard with package statistics

\- Add new packages

\- View package details

\- Mark packages as delivered

\- View order history

\- Settings page



\## Technologies Used



\- Next.js

\- React

\- JavaScript

\- Tailwind CSS

\- React Context



\## How to Run



1\. Clone or download the repository.

2\. Open the project folder in VS Code.

3\. Install dependencies:



&#x20;  `npm install`



4\. Start the development server:



&#x20;  `npm run dev`



5\. Open `http://localhost:3000` in your browser.
