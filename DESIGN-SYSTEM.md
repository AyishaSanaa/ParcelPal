# ParcelPal – Design Documentation

## 1. Page Design

ParcelPal uses a simple and organised dashboard layout. A sidebar provides navigation to Dashboard, My Packages, Order History and Settings. The main section displays package information and other features.

## 2. Colour Palette

The application uses purple and lavender as its primary colours to create a clean and consistent appearance.

- **Primary Colour:** Dark Purple (#30205c)
- **Secondary Colour:** Purple (#5835a5)
- **Accent Colour:** Lavender (#9272df)
- **Background Colour:** Light Lavender (#f7f6fc)
- **Card Colour:** White (#FFFFFF)
- **Text Colour:** Dark Grey (#374151)

## 3. Typography

The application uses the Geist font for clear and easy-to-read text.

- **Main Headings:** Bold, 24–32px
- **Section Headings:** Bold, 20–24px
- **Body Text:** Regular, 14–16px
- **Small Text:** Regular, 12–14px

## 4. Layout and Spacing

- A sidebar is used for navigation.
- The main dashboard displays package information.
- Cards are used to display package details and statistics.
- Rounded corners and consistent spacing keep the interface organised.
- The layout adjusts to different screen sizes.

## 5. UI Components

The project uses the following components:

- **Buttons:** Used for adding packages, saving details and marking packages as delivered.
- **Package Cards:** Display product names, shopping platforms and delivery status.
- **Statistics Cards:** Display total packages, packages on the way and delivered packages.
- **Input Fields:** Used to enter package information.
- **Navigation Menu:** Allows users to move between different pages.

## 6. Main Features

- Add and manage packages.
- View package details.
- Check and update delivery status.
- View delivered packages in Order History.
- Manage basic application preferences through Settings.

## 7. Design Goal

The main goal of ParcelPal's design is to provide a simple, user-friendly and organised interface that makes managing online orders easier.
